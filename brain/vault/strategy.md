# Operating Strategy

Virtual City is ONE system of many autonomous buildings. No single mega-brain
micromanages the others. City Hall (the Conductor) only coordinates: it reads
the north-star, holds meetings, and surfaces alerts.

## Principles (locked)
1. **Many orchestrators, one city.** Each building owns its loop, state, and decisions.
2. **Explicit interaction.** Buildings change each other's world through published events.
3. **Brain before action.** Every agent reads the Shared Knowledge Core before it acts.
4. **Budget and autonomy first.** No agent spends API money or takes destructive action
   outside its autonomy level and the city API budget.
5. **Inspectable by default.** Every run, decision, and event is logged and replayable.

## Operator posture
- Human-led buildings plan only; human-assisted may act on cheap skills; autonomous acts
  within budget and logs everything.
- North-star metrics define what "winning" means for the active persona.
