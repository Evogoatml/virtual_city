# Content Domain

- Content is the top of the growth funnel. A published post should carry the affiliate
  link for the active offer so Social Affiliates can convert it.
- Publish `content.published` with the offer + url so affiliates react.
- Content analytics measures views -> leads -> conversions; close the loop back to
  the affiliate funnel SOP.
